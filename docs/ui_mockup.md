## 交互说明

### 控制面板
- **启动/停止按钮**：大按钮，红色（停止）/绿色（运行中），点击切换状态。
- **音调滑块**：-24 到 +24 半音，步进 1，实时生效。
- **索引强度滑块**：0% 到 100%，控制音色相似度。
- **清音保护滑块**：0 到 0.5，保护辅音不被过度转换。
- **延迟显示**：只读标签，实时更新最近一次推理的延迟。

### 模型与设备选择
- **模型下拉框**：列出 `models/rvc/` 中扫描到的所有 `.pth` 模型。
- **刷新按钮**：重新扫描模型目录。
- **模型信息标签**：显示版本（v1/v2）和采样率（32k/40k/48k）。
- **输入/输出设备下拉框**：列出系统所有音频设备。
- **采样率显示**：根据当前模型自动匹配，或允许用户手动选择。

### 状态栏
- 左侧：运行状态（就绪/运行中/错误）。
- 右侧：GPU 名称和显存占用（如果可用）。
